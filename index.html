Salvamento e cópias de segurança

As alterações são salvas automaticamente neste navegador. Use exportação para guardar uma cópia e importação para recuperar seus dados.

Importante: este protótipo guarda dados no armazenamento local do navegador. Limpar os dados do navegador ou usar outro aparelho não transfere as informações. Para uma loja pública com login, banco de dados, pedidos centralizados e dados pessoais protegidos, é necessário configurar um backend seguro.

O HTML importado precisa conter os dados exportados da LUXX STORE AD. Um HTML genérico pode ser aberto, mas não é possível converter automaticamente qualquer site em produtos editáveis.
